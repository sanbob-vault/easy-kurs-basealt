# Easy Kurs Basealt

Скрипт, который позволяет удобно проходить курс в Альт Академии (kurs.basealt)

## Возможности

- Все кнопки, которые отвечают за переход на следующий шаг в модуле перенесены вправо вверх для удобства и сделаны большими. (Далее, Submit, Continue ...)
- Скрипт позволяет перейти дальше (кликнуть на кнопку перехода) нажатием клавиши "Enter"
- Скрипт позволяет выбирать вариант ответа с помощью цифр на клавиатуре для вопросов с одним вариантом ответа

## Установка

1. Установить в свой браузер расширение, которое поддерживает пользовательские скрипты (.user.js) и позволяет выполнять js код на страницах, такое, например, как [Tampermonkey](https://www.tampermonkey.net/)
2. Открыть [скрипт](https://raw.githubusercontent.com/sanbob-vault/easy-kurs-basealt/refs/heads/main/script.user.js), он автоматически подгрузиться в Tampermonkey
