# Easy Kurs Basealt

Скрипт, который позволяет удобно проходить курс в Альт Академии (kurs.basealt)

## Возможности

- Все кнопки, которые отвечают за переход на следующий шаг в модуле перенесены вправо вверх для удобства. Теперь можно перейти дальше при нажатии кнопки "enter
- Выбор варианта ответа (где только один вариант ответа) с помощью цифр на клавиатуре
