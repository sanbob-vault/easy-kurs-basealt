# Easy Kurs Basealt

Пользовательский скрипт (UserScript) для быстрого и комфортного прохождения курсов в Альт Академии ([kurs.basealt.ru](https://kurs.basealt.ru/)).

## Возможности

- **Закрепленные кнопки навигации:** ключевые кнопки перехода (`Далее`, `Submit`, `Continue`, `Try again`) вынесены в правый верхний угол экрана, увеличены в размере и всегда остаются под рукой независимо от прокрутки страницы.
- **Пропуск теории в один клик:** кнопка `⏩ Пропустить теорию` автоматически открывает последний пункт блока теории и сразу переходит к контрольным вопросам по теме.
- **Быстрый выбор ответа (1–9):** варианты с одиночным выбором пронумерованы - нужный пункт можно мгновенно выбрать соответствующей цифрой на клавиатуре.
- **Переход по Enter:** отправка формы (`Submit`) или переход на следующий шаг (`Далее` / `Continue`) срабатывают по нажатию клавиши `Enter`.
- **Защита ввода:** горячие клавиши не срабатывают, если вы вводите текст в поисковой строке, комментариях или текстовых полях.

## Установка

1. Установите расширение для браузера с поддержкой пользовательских скриптов - например, [Tampermonkey](https://www.tampermonkey.net/).
2. Откройте [скрипт](https://raw.githubusercontent.com/sanbob-vault/easy-kurs-basealt/refs/heads/main/script.user.js).
3. Tampermonkey автоматически откроет окно установки - нажмите кнопку **«Установить»**.
